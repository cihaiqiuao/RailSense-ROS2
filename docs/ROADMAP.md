# 路线图

## V1

- ROS2 包骨架。
- 自定义接口。
- IMU、GPS、Laser driver 节点。
- 第一版融合节点和列车状态输出。

## V2

- GStreamer camera publisher。
- RViz 可视化。
- rosbag2 录制和回放流程。

## V3

- ONNX Runtime YOLO 姿态检测。
- 车钩状态消息。
- 可选 TensorRT 加速路径。

## V4

- `ros2_control` 探索。
- CAN driver。
- EtherCAT driver。

## V5

- Docker 部署。
- GitHub Actions 自动构建。
- Benchmark 与性能报告。
